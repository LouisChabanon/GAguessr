# Pin it

A map placement game. A name appears (a country, a city, a French nuclear plant…), and you drop a pin on a blank map. The closer you land, the more points you score: up to 5,000 per round. Countries and Cities games last 10 rounds; the nuclear plants game covers all 18 plants.

Built with Next.js 16 (App Router, Cache Components), React 19, `d3-geo` and `d3-zoom`. It runs fully offline, with no map API key.

Answers revealed in earlier rounds stay on the map until the game ends.

## Map rendering

- **The basemap is drawn on `<canvas>`.** Each feature is projected once into a `Path2D` with its projected bounds. Panning and zooming only change the canvas transform: redraws are coalesced to one per animation frame and skip features that are off-screen. The pins, the distance line and the highlighted answers live in a small SVG overlay.
- **Level of detail on the world map:** 1:110m up to ×2.5 zoom, then 1:50m. The 1:50m level is prefetched while the page is idle. Countries mode always scores against the 1:50m geometry.
- **City labels** on the France map are drawn in screen space at a constant size. A greedy layout places them right, left, above or below their dot, so labels never overlap. Secondary cities appear only once the map is large enough on screen (after zooming in, on phones).
- Floating panels are near-opaque instead of using `backdrop-filter`, because blurring a moving map on every frame is expensive.

## Map data

| File | Content | Source |
| --- | --- | --- |
| `public/geo/countries-110m.json`, `countries-50m.json` | World countries | [Natural Earth](https://www.naturalearthdata.com/) via [`world-atlas`](https://github.com/topojson/world-atlas) (public domain) |
| `src/data/fr-cities.json` | 26 major French cities, drawn as labelled landmarks on the France map | Hand-curated coordinates |
| `public/geo/france.json` | 13 metropolitan regions, about 20 major rivers, neighbouring countries | Regions: [france-geojson](https://github.com/gregoiredavid/france-geojson) (IGN/INSEE, Licence Ouverte). Rivers: Natural Earth 10m (public domain) |

`france.json` is generated by `npm run build:geo` (`scripts/build-france-geo.mjs`). The script downloads the sources, fixes ring winding for d3, keeps an allow-list of rivers, and simplifies the result to about 170 KB. The output is committed.

## How scoring works

`score = round(5000 · e^(−distance / scaleKm))`. Each mode sets its own `scaleKm`, the distance at which a guess keeps about 37% of the points:

- **Point targets** (cities, plants): great-circle distance to the location.
- **Area targets** (countries): 0 km if you click inside the borders, otherwise the distance to the nearest border vertex.

## Adding a game mode

1. Add a dataset to `src/data/` and a mode file in `src/modes/`. Validate the dataset with zod and turn it into `PointTarget`s or `AreaTarget`s. `fr-nuclear-plants.ts` is a small, complete example.
2. Pick a `region` from `src/lib/geo/regions.ts`, or add one: a projection plus `loadBasemap()`, which returns layers (`fill`: land/muted/region, `line`: river) and, optionally, a more detailed level to load on zoom.
3. Set `roundsPerGame` to a number, or to `"all"` to play every target once.
4. Add the mode to `GAME_MODES` in `src/modes/registry.ts`. The home page and the `/play/[mode]` route pick it up automatically.
5. Add dataset sanity tests to `src/modes/modes.test.ts`, for example "every point lies inside its region".

## Project layout

```
src/
├── app/                 # routes: home, /play/[mode]
├── components/          # map (canvas basemap + SVG overlay + zoom), hud, summary, ui
├── data/                # static datasets (JSON)
├── game/                # pure game logic: reducer, scoring a guess, picking targets
├── hooks/               # useGame, useBestScore (localStorage)
├── lib/geo/             # distances, polygon proximity, atlas loading, regions
├── lib/map/             # viewport maths: fitting, reveal framing, click inversion, culling
└── modes/               # game mode definitions + registry
```
